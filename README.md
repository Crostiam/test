# Fighthing Street (HTML5 Canvas) — Menu, VS AI, Animations & Sounds

Press "Play" to start the round—AI behavior (movement/attacks) is enabled only after you press Play. The P2 (AI) health bar is explicitly initialized and visible.

## How to run

- Open `index.html` in a modern browser (Chrome, Edge, Firefox, Safari).
- Or serve with a local web server:
  - Python: `python3 -m http.server` then visit http://localhost:8000
  - Node: `npx serve` or `npx http-server`

Tip: Clicking "Play" unlocks audio on most browsers.

## Controls

- You (Player 1):
  - Move: A / D
  - Jump: W
  - Light: J
  - Heavy: K
- System:
  - Play: Click the "Play" button (or press Enter/Space on the menu)
  - Reset Round: R
  - Pause: P
  - Toggle Debug Boxes: ` (backtick)
  - Toggle Mute: M
  - Cycle AI Difficulty: H
